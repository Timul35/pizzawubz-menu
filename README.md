# Le Menu de Wubz – Fuel Station Intergalactique

Bienvenue dans l’unique station de recharge gustative certifiée **par aucun syndicat officiel** !

Ici, Wubz cuisine pour les pilotes affamés, les mécanos pas réveillés, les contrebandiers pressés et même les droïdes curieux.

**Au programme :**  
– Snacks grillés avec amour (et parfois des restes)  
– Pizzas colorées comme un trafic de néons à Coruscant  
– Desserts boostés au sucre spatial  
– Boissons sorties d’un compresseur de vaisseau (presque propres)

> _“Si t’as pas encore fondu une papille ou pleuré sur une bouchée, t’as pas encore goûté Wubz.”_  
— Wubz, fier propriétaire, cuistot, et survivant du marché de Batuu.
